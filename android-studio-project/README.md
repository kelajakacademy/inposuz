# 📱 BarPOS Android Studio Loyihasi (APK Build Guide)

Ushbu loyiha **BarPOS Restoran & Kafe tizimi** uchun maxsus tayyorlangan Android Studio ilovasi hisoblanadi.

---

## 🛠 APK Fayl yaratish (Build APK) bo'yicha ko'rsatma:

### 1-Qadam: Android Studio'da ochish
1. **Android Studio** dasturini oching.
2. Bosh sahifada **"Open"** (yoki **File -> Open**) tugmasini bosing.
3. `android-studio-project` jildini tanlang va **OK** bosing.
4. Android Studio loyihani va Gradle kutubxonalarini avtomatik yuklab oladi (Sync tugashini kuting).

---

### 2-Qadam: APK faylni yig'ish (Build APK)
1. Yuqori menyudan **Build** menyusiga kiring.
2. **Build Bundle(s) / APK(s)** -> **Build APK(s)** tugmasini bosing.
3. 1-2 daqiqada APK tayyor bo'ladi va pastki o'ng burchakda **"APK(s) generated successfully"** degan xabar chiqadi.
4. **"locate"** havolasini bosing: tayyor **`app-debug.apk`** fayl ochiladi!

Ushbu `.apk` faylni har qanday Android telefon yoki planshetga o'rnatib ishlatishingiz mumkin.

---

## 🚀 Ilova imkoniyatlari:
- ⚡ **To'liq POS va Buyurtmalar integratsiyasi** (Bulutli va lokal rejim).
- 📶 **Offline holatni aniqlash** va qayta ulanish tugmasi.
- 🔄 **Pull-to-refresh** (Ekranni pastga tortib yangilash).
- ⚙️ **Server manzilini o'zgartirish** (Local Wi-Fi POS serveri yoki Cloud server URL).
- 🖨 **Bluetooth / Termal printerlar** va uskunalar bilan ishlash ruxsatnomalari.
